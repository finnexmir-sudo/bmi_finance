BMI Finance — Əsas səhifə üçün 4 dizayn təklifi

Mövcud sol sidebar çox sıx (10+ alt-maddə, 5 qrup, 3 səviyyə) göründüyü üçün 4 fərqli istiqamət hazırlamışam. Hər faylı açıb real ölçüdə görə bilərsən.

Tövsiyəm: Sənin layihə (ASP.NET MVC, çoxlu rol, dərin menyu strukturu) üçün ən praktik seçim Variant 4 (Hibrid)-dir — mövcud Cshtml-ə ən az toxunuşla sol menyunu sadələşdirir, dashboard-u isə KPI kafelləri ilə "giriş nöqtəsi"nə çevirir. Əgər "tamamilə yeni görkəm" istəyirsənsə — Variant 2 (İkon Rail) peşəkar və müasir alternativdir.
Variant 1

Üst Navbar + Mega Menu

Sidebar tamamilə yoxdur. Bütün bölmələr yuxarıda, hover-də mega-dropdown açılır. Geniş iş sahəsi.

✓ Maksimum iş sahəsi · Müasir SaaS görünüşü
⚠ Çox dərin menyu olan rollar (HR/Admin) üçün mega geniş olur
→ Aç Variant 2

İkon Rail + Kontekstli Panel

VS Code üslubu: 68px dar ikon lenti + seçilən bölmənin kontekstli menyusu. İkinci panel bağlana bilər.

✓ Həmişə təmiz · Müasir · İki panel — favoritlər/son açılan
⚠ Tooltip tələb edir — ilk öyrənmə əyrisi var
→ Aç Variant 3

Minimal Top + Command Palette

Sidebar yoxdur, üstdə yalnız 2-3 tab. Hər şey Ctrl+K ilə əmr paletindən. Dashboard "kafel şəbəkəsi"dir.

✓ Ən təmiz · Peşəkar istifadəçi üçün çox sürətli
⚠ Qısayol mədəniyyəti tələb edir · Banka uyğun olmaya bilər
→ Aç Variant 4 — TÖVSİYƏ

Hibrid: Sadə Sidebar + Rol Dashboard

Sol menyu 5 qrupa endirilib. Köhnə alt-maddələr KPI kafelləri və Dashboard qrafikləri ilə əvəz olunur.

✓ Mövcud MVC-ə ən az dəyişiklik · Rol-bazlı KPI-lar · Təqvim, müraciət, maaş hamısı görünür
⚠ Sidebar hələ də qalır — amma tam iki dəfə qısadır
→ Aç
Əlavə təkliflər (hər variantla birləşdirilə bilər): • Ctrl+K axtarış — hamısında ortaq əlavə edilsin (sürətli səhifə keçidi)
• Favoritlər — istifadəçi tez-tez açdığı səhifələri sol menyuya sancsın
• Son açılan səhifələr — avtomatik izlənsin və sürətli-bax paneli yaratsın
• Role switcher — bir istifadəçidə bir neçə rol varsa, üstdə dəyişdirilsin
• Sidebar "collapse" düyməsi — istifadəçi istədiyi an daraltsın (68px rail görkəminə)
• Breadcrumb — hansı səhifədə olduğunu həmişə göstərsin
