# FinNex — Корпоративная HR и Финансовая Система BMI Finance

## Что это такое?

**FinNex** — это внутренняя корпоративная система управления персоналом и финансами, разработанная специально для BMI Finance. Система автоматизирует весь цикл работы с сотрудниками: от найма до увольнения, включая зарплату, отпуска, посещаемость, командировки, расходы и многое другое. Работает через браузер, доступна всем сотрудникам и руководителям.

---

## Основные модули

### 1. Управление персоналом (HR)
- Личные карточки сотрудников (данные, должность, отдел, стаж)
- История изменения зарплат
- Управление должностями и структурой компании
- Контракты: продление и расторжение
- Пробный период сотрудников

### 2. Посещаемость и ADMS
- Автоматическая фиксация прихода/ухода через устройства ADMS
- Ежедневный табель посещаемости для каждого сотрудника
- Автоматическая отметка "Отсутствует" в 23:00 для не явившихся
- Ранний уход с разрешения руководителя
- Панель руководителя: кто пришёл, кто опоздал, кто отсутствует (в реальном времени)
- Экспорт в Excel

### 3. Отпуска
- Онлайн-заявка на отпуск от сотрудника
- Многоступенчатое согласование (Начальник отдела → Руководитель → HR)
- Автоматический расчёт рабочих дней
- Баланс отпусков по годам (FIFO-списание, LIFO-восстановление)
- Автоматическое восстановление баланса при отмене отпуска
- Оплата отпуска

### 4. Расчёт зарплаты
- Расчёт зарплаты по месяцам
- Налоговые вычеты (НДФЛ, DSMF и др.)
- Надбавки, бонусы, удержания
- Авансы сотрудникам
- Расчётные листки
- Периодические выплаты

### 5. Командировки
- Заявка на командировку с указанием места и дат
- Согласование руководителем
- Отслеживание выезда/возвращения через ADMS
- Автоматическое закрытие незавершённых командировок ночью

### 6. Больничные и отгулы
- Регистрация больничных листов
- Отгулы (краткосрочные отлучки с отметкой времени выхода/возврата)
- Автоматическое обновление статуса посещаемости

### 7. Расходы и бюджет
- Заявки на расходы с прикреплением счетов
- Категории расходов
- Планируемые расходы
- Бюджет компании и отдела
- Отчёты по расходам

### 8. Обучение и развитие
- Регистрация тренингов
- Учёт участников
- Сертификаты

### 9. KPI и рейтинг сотрудников
- Оценка эффективности (KPI)
- Рейтинговая система с баллами
- Токены/значки за достижения
- Ежеквартальные/годовые оценки

### 10. Корпоративные мероприятия (Тедбирлэр)
- Создание корпоративных событий
- Список участников с чекбоксами
- Статусы: Планируется / Идёт / Завершено / Отменено
- Отслеживание участия через ADMS (оффлайн-мероприятия)
- Поиск и фильтрация по статусу

### 11. Задачи и поручения
- Создание задач с дедлайном и исполнителем
- Комментарии к задачам
- Статусы выполнения
- Напоминания
- Предложение задачи после утверждения отпуска

### 12. Внутренние коммуникации
- Внутренний чат между сотрудниками
- Уведомления в реальном времени
- Объявления (Эланлар)
- Входящая корреспонденция

### 13. Кредитный модуль
- Заявки сотрудников на кредит
- Рассмотрение комитетом
- Решение с подписями
- Запись на встречу (Рандеву)
- SMS-уведомления

### 14. Документооборот
- Создание и хранение документов
- Шаблоны документов
- Права доступа к документам
- Теги и поиск

### 15. Платёжные поручения
- Создание платёжных поручений
- Управление банками и счетами
- Клиенты и их счета

### 16. AI-ассистент (HR Советник)
- Загрузка законов и внутренних правил
- Вопросы к документам через AI
- Анализ документов
- Конструктор документов

### 17. Административная панель
- Управление пользователями и ролями
- Права доступа
- Системные настройки
- Журнал активности (кто что делал и когда)
- Журнал входов в систему
- Oracle-запросы (интеграция с банковской системой BMI)

### 18. Панели руководителей
- **HR Dashboard**: сводка по всей компании
- **Rehber (Руководитель) Dashboard**: своя команда, посещаемость, одобрение заявок
- **Финансовый Dashboard**: расходы, бюджет

## Технические характеристики

| Параметр | Значение |
|---|---|
| Платформа | ASP.NET Core 8 MVC |
| База данных | SQL Server (основная) + Oracle BMI (только чтение) |
| Аутентификация | ASP.NET Core Identity |
| Сервер | Windows Server 2022, IIS |
| Интеграция | ADMS (устройства контроля доступа), Oracle BMI |
| Хранение файлов | C:\FinNex_DMS\ |
